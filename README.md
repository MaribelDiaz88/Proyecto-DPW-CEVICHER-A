# Cevichería Mary

## Descripción

Sitio web informativo y corporativo desarrollado con HTML, CSS y JavaScript para promocionar la cevichería "Mary".
El sitio está diseñado para atraer nuevos clientes y facilitar la interacción con los comensales, mostrando la calidad y frescura de sus platos.

Objetivos del sitio:
* Mostrar el menú de pescados y mariscos.
* Promocionar los platos bandera y promociones especiales.
* Adaptarse perfectamente a dispositivos móviles (Responsive Design).
* Facilitar el contacto directo con los clientes para reservas y pedidos.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Visual Studio Code

## Características del sitio

* Diseño Responsivo: Se adapta a celulares, tablets y computadoras.
* Menú Digital: Muestra los platos de pescados y mariscos con sus precios.
* Galería de imágenes: Fotografías atractivas de los platillos y el local.
* Formulario de Contacto: Facilita que los clientes hagan reservas o consultas.
